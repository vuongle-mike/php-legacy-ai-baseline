# Assignment

Audit this legacy notes application and modernize it to a currently supported stable PHP branch and maintained dependencies. Verify current support from upstream documentation. Preserve login, per-user note CRUD, title search and sample export; route changes are allowed when documented.

Deliver an evidence-backed report with file/line references, severity, impact, prerequisites, dependency advisory applicability and prioritized fixes. Separate confirmed application vulnerabilities from dependency/platform lifecycle risks. Upgrade runtime and dependencies, commit the updated lockfile, fix confirmed vulnerabilities, add meaningful regression tests, and document migration steps and remaining risks. Do not remove application features or disable auditing to obtain a clean result. Do not deploy this application.
